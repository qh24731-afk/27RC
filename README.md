### 主题背景

古代工程师建造了规模宏大的神庙群作为能量网络，位于最高处的秘宝（Mustika）是启动整个努桑塔拉能量网络的圣物。岁月使基座损毁、网络沉寂。参赛队须重建石质建筑（塔），最终把秘宝安放到中央柱上，使能量网络重新启动。

比赛是一场持续 3 分钟、围绕**垂直运输与建造**展开的高强度较量：
- **运输机器人（TR）**：灵活的采集者，在地面收集地基块并送往交接区。
- **建造机器人（BR）**：完全自主运行的建造者，在一级/二级平台上堆叠方块重建塔柱，最后以天空块封顶，并将秘宝安放在最高的中央柱上。

## 二、对阵方式与基本概念

- 每场比赛由**红队**与**蓝队**对抗，单场 **3 分钟**，以累计总分决定胜负。
- 每队使用**两台机器人**：一台运输机器人 **TR** + 一台建造机器人 **BR**。
- **TR**：可手动控制，也可全自动。负责从地面收集方块并运至交接区。
- **BR**：**必须全自动**（无人手动干预独立运行）。负责在 L1、L2 建塔，并将秘宝安放于中央柱。

### 机器人活动区域（严格限制）

| 机器人 | 允许活动区域 |
|--------|--------------|
| TR | 地面区 + 交接区；**严禁**进入 L1 交接区以外区域，**严禁**进入 L2 |
| BR | 交接区 + L1 + L2；**不得**下降进入地面区/储存区（重试或驶上 L1 阶梯过程除外） |

> 越区判定：以机器人任何部分的**竖直投影**是否越入受限区域为准。

## 三、比赛场地详解

场地总尺寸 **11000 mm × 11000 mm**，划分为红蓝双方各自的指定活动区域。

### 3.1 地面层（Ground Area）— TR 主战场

| 区域 | 尺寸 / 规格 | 说明 |
|------|------------|------|
| 启动区 Start Zone | 700 × 700 mm ×2 | 比赛开始 TR、BR 各居其一，可自行分配 |
| 储存区 Storage Area | 1000 × 2000 mm | 每队 20 个地基块放置于此，每列最多叠 2 个 |
| 地面共享区 Shared Area | 1200 × 1200 mm | 中央争夺区，**12 个天空块**按 5×5 网格交替棋盘格摆放，正中留空 |
| 秘宝柱 Mustika Pillar | 高 500 mm，直径 270 mm | 顶部凹形承托槽：直径 180 mm，深 100 mm |
| 秘宝柱周围共享区 | 1000 × 1000 mm | 双方均可进入 |

**天空块初始布局要点：**
- 采用"角度交替"摆放：红蓝方向在南北向与东西向之间交替旋转 90°，增加取块难度。
- 顶面颜色关于中央列镜像对称：第 c 列与第 6−c 列颜色相反；中央列两个天空块一红一蓝朝上。
- 目的：保证双方在与己方区域等距位置、以相同条件接触本队颜色朝上的方块。

### 3.2 一级平台 L1 — BR 建塔区之一

| 项目 | 规格 |
|------|------|
| 高度 | 高出地面 **600 mm** |
| 尺寸 | 6000 × 6000 mm |
| 进入方式 | 长 3500 mm 的**斜坡**或**阶梯** |
| 阶梯每级 | 长 300 mm × 宽 1000 mm × 高 150 mm |

### 3.3 二级平台 L2 — 高分共享区

| 项目 | 规格 |
|------|------|
| 高度 | 高出 L1 **300 mm**（即高出地面 **900 mm**） |
| 尺寸 | 3000 × 3000 mm |
| 属性 | **整个 L2 为共享区**，双方均可建塔 |
| 阶梯每级 | 长 300 mm × 宽 1000 mm × 高 150 mm |

### 3.4 关键功能点

| 名称 | 规格 | 说明 |
|------|------|------|
| 交接区 Transfer Area | L1 边界处 1000 × 1000 mm | TR 与 BR 在此交接物件 |
| 建塔位 Building Spot | 500 × 500 mm 绿色方格 | 位于 L1（专属区+共享区）与 L2（全共享区），完整塔必须由 BR 在此搭建 |
| 中央柱 Central Pillar | 高 800 mm，直径 270 mm | 位于 L2 最高处，顶部凹形承托槽直径 180 mm、深 100 mm，用于放置秘宝 |

## 五、比赛流程

1. **布置阶段**：赛前 1 分钟布置机器人，确定策略。TR、BR 完全位于各自启动区，任何部分（含机构、夹具、传感器）不得越出启动区竖直边界。
2. **比赛开始**：裁判蜂鸣器/哨声响起，比赛立即开始。比赛期间仅 3 名正式队员可进入场地。
3. **核心循环**：
   - TR 从储存区收集地基块、从地面共享区收集天空块 → 运至 L1 交接区；
   - TR 与 BR 在交接区交接物件（可直交，或放于交接区地面由 BR 取走）；
   - BR 在 L1、L2 建塔位搭建完整塔；
   - 满足圣所条件后，TR 取秘宝 → 交接给 BR → BR 安放于 L2 中央柱。
4. **比赛结束**：180 秒蜂鸣器响起，所有机器人立即停止。以**结束瞬间**各方块与秘宝的状态统计总分。**即使秘宝已安放，比赛也不提前结束**，双方可继续建塔或翻转天空块刷分。

### 携带上限
- **TR**：任意时刻最多携带 **3** 个方块。
- **BR**：任意时刻最多携带 **2** 个方块。

### 搬运规则（重要）
- 移动方块必须**抬起并携带**；沿地面推、拖、滑方块至建塔位或交接区均属违规。
- 交接必须完全在交接区边界内完成；交接中物件掉落或在区外释放视为交接违规。
- 交接阶段允许 TR 与 BR 实体接触，但两者均须保持在交接区边界内。

## 六、计分规则

### 6.1 交接得分（TR 任务）
- 每成功送入交接区 **1 个方块（地基块或天空块）得 5 分**。
- 成立条件：TR 释放后方块完全保持在交接区竖直边界内即"已送达"。
- **永久有效**：即便 BR 随后取走用于建塔，此 5 分也不取消。

### 6.2 建塔得分（BR 任务，单个方块）

| 比赛物件 / 位置 | L1 得分 | L2 得分 |
|-----------------|:------:|:------:|
| 地基块（第一层/底层） | 10 | 20 |
| 地基块（第二层/中层） | 20 | 40 |
| 天空块（顶层） | 40 | 80 |

> **一座完整 L1 塔 = 10 + 20 + 40 = 70 分**
> **一座完整 L2 塔 = 20 + 40 + 80 = 140 分（是 L1 的 2 倍）**

### 6.3 归属权与单块计分
- 除天空块外，塔中每个方块按**实际放置它的队伍**独立计分，锁定归属。即便对方后来在其上堆放，也不能取得该地基块的分数。
- **天空块**按**比赛结束时朝上的颜色**判定归属：红朝上归红队（40 或 80 分），蓝朝上归蓝队。
- 翻转天空块**不会**改变下方地基块的归属。

### 6.4 混合建造的塔
- 共享区（L1 共享区 / L2）内，一座塔可由双方共同堆放组成。
- 例：红队在 L2 放第一层地基块得 20 分；蓝队随后在其上放第二层地基块得 40 分。红留 20，蓝得 40。

### 6.5 完整塔与"夺取"机制
- **完整塔**：两个地基块竖直堆叠（底层+中层），其上放置一个天空块，且天空块朝上颜色与该队一致。
- 各队可**翻转/调整任意塔上的天空块**使本队颜色朝上，从而把该塔完整塔归属从对方手中"夺取"过来。

### 6.6 任务得分（秘宝）
- 成功将秘宝安放到 L2 中央柱并保持稳定：**+250 分**。
- 前提：必须已满足圣所条件。

### 6.7 不计分情形
- 蜂鸣器响起时仍被机器人接触、夹持或支撑的物件。
- 未按完整塔顺序（地基块→地基块→天空块）放置的方块。
- 被撞出比赛场地的方块。
- 沿地面推、拖、滑到建塔位的方块。

## 七、圣所条件与秘宝

- **圣所条件（Sanctuary Mandate）**：成功完成**至少两座完整塔**，且其中**至少一座位于共享区**（L1 共享区或 L2 共享区）。
- 满足圣所条件后，TR 方可从秘宝柱取走秘宝。**一旦满足并取走秘宝即永久满足**，即便完整塔随后被对方改变也不再取消资格。
- 流程：TR 取秘宝 → 在交接区交给 BR → BR 携带秘宝运至 L2 → 安放在中央柱。

---

## 八、胜负判定

总分最高者胜。总分 = 交接分 + 建塔分 + 秘宝分。

**平分判定顺序：**
1. 成功将秘宝安放在中央柱上的队伍优先；
2. 在 L2 建塔位上正确放置的地基块与天空块**总数**更多的队伍优先；
3. 全场塔顶中，天空块以本队指定颜色朝上的**数量**更多的队伍优先；
4. 仍平分则由裁判组根据技术表现与体育道德最终评定。

## 九、重试与违规

### 重试（Retry）
- 机器人故障、受困或需调整策略时可申请：队长举手高喊"**Retry!**"，裁判确认吹哨后生效。
- TR 必须返回启动区（地面重试区）；BR 可选返回启动区或 L1 重试区。
- 重试时携带的方块须返回初始位置；携带秘宝须放回秘宝柱。**重试期间计时不暂停**。

### 违规（导致强制重试）
- **禁止推移**：未抬起而沿地面推、拖、滑方块。
- **越区**：TR 越入 L1 交接区以外区域或 L2；任何机器人越入对方专属区域。
- **交接违规**：在交接区竖直边界外交换物件。
- **出界**：方块被撞出场地则永久移出；秘宝出界立即放回秘宝柱。
- **物件掉落**：掉落后必须主动抬起才能继续搬运；秘宝掉落须立即放回秘宝柱。
- **共享区阻挡**：未执行技术任务而故意阻挡对方通行超过 5 秒（裁判 5 秒倒数）。

### 取消资格（本场记 0 分）
- 故意损坏场地、物件或对方机器人；
- 故意移动/取走/干扰对方已正确放置的地基块；
- 安全违规（尖锐部件飞脱、电池冒烟起火等）；
- 未经许可用手触碰机器人、场地或物件；
- 违反体育道德的行为。

## 十、机器人技术规格

| 项目 | TR | BR |
|------|----|----|
| 控制方式 | 手动或全自动 | **必须全自动** |
| 启动尺寸 | ≤ 700×700×700 mm | ≤ 700×700×700 mm |
| 展开尺寸 | ≤ 1000×1400×1200 mm（宽×长×高） | ≤ 1000×1400×1200 mm |
| 质量 | 含电池/控制器/电缆 ≤ 50 kg | ≤ 50 kg |

### 电气与动力
- 电池标称电压 ≤ 24 V（串联组合总标称电压 ≤ 24 V）；
- 动力电路实际最高电压 ≤ 42 V（多隔离系统各自 ≤ 42 V）；
- 气压系统 ≤ 600 kPa，须用专用气动容器或合格塑料瓶；
- 动力来源仅限电池、压缩空气和/或弹性力。

### 通信
- 控制器与机器人间仅允许 **Wi-Fi（IEEE 802.11）、Zigbee（IEEE 802.15）、蓝牙**；
- **严禁 TR 与 BR 之间无线通信**；
- 主办方不保证场馆无线信号质量。

### 禁用项
- 铅酸电池、胶粘密封电池、爆炸性或高温能源；
- 不符合 IEC 60825-1 标准 1 类/2 类的激光器；
- 飞行机构或无人机；
- 吸附机构不得留下残留物或造成实体损坏。

### 安全
- 每台机器人须装清晰可见、便于触及的**红色紧急 STOP 按钮**（强烈建议另配远程急停）；
- 设计制造须确保队员、对方队员、工作人员及场地设施绝对安全。

## 十一、参赛队组成

- 每队**恰好 3 名学生队员 + 1 名指导教师**，须来自同一高等教育机构；
- 可另登记最多 3 名维修区队员（Pit Crew），仅限维修区协助，比赛期间禁入场地；
- 正式队员与维修区队员仅限本科生或专科/文凭课程学生，研究生不得以此身份参赛。
