## 1. 设计总则

### 1.1 已固化决策
| 项目 | 决策 |
|------|------|
| BR 爬楼 | 地面→L1 走斜坡（~10°）；L1→L2 爬 2×150 mm 阶梯（规则限定） |
| BR 堆叠 | 竖直举升平台 + 夹爪 |
| TR 控制 | 纯手动遥控（Wi-Fi/蓝牙链路） |
| 软件栈 | ROS 2 Humble + Nav2 + RealSense/OpenCV + ros2_control + 行为树 |

### 1.2 硬性设计约束（来自规则，不可违反）
| 约束 | 数值 | 影响 |
|------|------|------|
| 启动尺寸 | ≤ 700×700×700 mm | 整机必须折叠进 700 立方 |
| 展开尺寸 | ≤ 1000×1400×1200 mm | 举升/夹爪最大工作高度受 1200 限制 |
| 整机质量 | ≤ 50 kg（含电池/控制/线缆） | 结构轻量化 |
| 电池标称电压 | ≤ 24 V | 选 6S LiPo(22.2V) 或 24V LiFePO4 |
| 动力电路电压 | ≤ 42 V | 常规低压设计即可 |
| 气压（如用） | ≤ 600 kPa | 夹爪若气动需配安全容器 |
| TR↔BR 通信 | **禁止无线互联** | 交接纯物理，时序不可协商 |
| BR 自主性 | **必须全自动** | 无人干预，需完善异常恢复 |
| 必备 | 红色紧急 STOP 按钮 ×2 | 硬件急停回路 |

## 2. 180 秒节拍预算（先算账，再设计）

> 这是全队的"时间宪法"。所有机构速度指标都从这里反推。

**理论得分模型：** 1 座完整塔 = 3 块（2 地基 + 1 天空）。解锁秘宝需 2 座塔（≥1 座共享区）。

| 阶段 | 动作 | 预算 | 累计 |
|------|------|:----:|:----:|
| A | BR 取块(交接区)→L1 专属区建第 1 座塔(3 层) | 55 s | 55 s |
| A | BR 取块→L1/L2 共享区建第 2 座塔(3 层) → **解锁圣所** | 55 s | 110 s |
| B | TR 取秘宝→交接区交 BR | 20 s | 130 s |
| B | BR 携秘宝上 L2(爬阶梯)→中央柱安放 → **+250** | 35 s | 165 s |
| C | 剩余时间：翻对方塔顶 / 巩固 L2 方块数 | 15 s | 180 s |

**结论与反推：**
- **保底目标 = 2 座 L1 塔 + 秘宝 ≈ 140 + 250 + 交接分（≥30）≈ 420+ 分**，这是能赢球的基准线。
- 留给 BR **单座塔的时间 ≈ 55 s**，分解为：交接区取块 10 s + 移动对准 20 s + 堆 3 层 25 s（**单层堆叠 ≤ 8 s**）。
- 这条"**单层堆叠 ≤ 8 s**"就是举升+夹爪+视觉伺服的核心速度指标。
- L2 高倍率塔（140 分）只有在 BR 节拍显著快于预算时才去冲；**秘宝优先级永远最高**。

## 3. BR 建造机器人 · 机械设计

### 3.1 总体布局
```
        ┌─────────────────────────┐
        │   顶部: 夹爪 + 2 工位缓存   │  ← 展开 ≤1200mm
        │   ┌───────────────┐     │
        │   │  竖直举升台     │     │  ← 行程 ~800mm
        │   │ (丝杠/剪叉)     │     │
        │   └───────────────┘     │
        │   RealSense(前) + 补光    │
        │   ┌───────────────┐     │
        │   │  全向底盘       │     │  ← 含越障
        │   │ 4×大轮+悬挂     │     │
        │   └───────────────┘     │
        └─────────────────────────┘   ← 折叠 ≤700mm
```
质心尽量放低（电池、驱动器贴底盘），举升部分用轻质材料（铝型材/碳纤维板）。

### 3.2 底盘（含 L2 越障，本项目最大机械难点）

**需求三合一：** ①爬 10° 斜坡 ②爬 2×150 mm 台阶 ③全向平移/原地旋转做堆叠对准。

| 子系统 | 设计 | 参数 / 说明 |
|--------|------|------------|
| 轮系 | **4 × 大直径全向轮（Omni）** | 轮径 **≥ 250 mm**（台阶 150 mm < 轮半径 125 mm 更易翻越）；麦轮辊子会卡台阶，**禁用纯麦轮** |
| 悬挂 | 4 轮独立摆臂 + 弹簧 | 保持越障时四轮接地、质心平稳 |
| 越障辅助 | 前部**可俯仰越障导板/辅助小轮** | 上台阶时先搭边，主轮借力翻越 150 mm |
| 驱动 | 4 × 带编码器减速电机 + 驱动器 | 单轮堵转扭矩按爬坡校核（见 §7） |
| 姿态 | IMU（爬坡俯仰反馈） | 坡道速度闭环，防冲坡/溜坡 |
| 防跌 | 4–6 × 超声/TOF 朝下 | 检测平台边缘，紧急制动 |

**上台阶动作序列（自动）：** 低速贴近 → 前导板搭上台沿 → 前摆臂轮爬上 → 质心前移 → 后轮翻越 → IMU 确认水平。**全程低速大扭矩，禁止冲台。**

### 3.3 竖直举升 + 夹爪

| 项目 | 设计 | 关键参数 |
|------|------|---------|
| 举升形式 | 同步带/丝杠驱动的**二级剪叉**或**滑台模组** | 折叠/展开比满足 700→1200 |
| 工作高度 | 最低 ≤150 mm（夹平台上 350 块） | 最高 ≥950 mm（放 900 塔顶天空块） |
| 有效行程 | **≥ 800 mm** | 由 1200 展开上限反推结构 |
| 负载 | ≥ 2 kg（夹爪 + 秘宝 0.44 kg + 裕量） | 升降时间：全行程 ≤ 6 s |
| 夹爪 | 平行开合自适应夹爪，内衬防滑 | 兼容 350 地基块 / 200 天空块 / Ø200 秘宝球 |
| 放置精度 | 机械 V 型导向 + 视觉伺服 | 落块偏差 ≤ ±10 mm |
| 缓存 | 举升台两侧 **2 工位**暂存（携带上限 2） | 取 2 块→连续堆，减少往返 |

**放秘宝自对中：** 夹爪下方加**锥形导向罩**，利用中央柱凹槽（Ø180×100）的锥度，让球在 100 mm 容差内自行滑入凹槽居中，放置后**停顿 1 s 确认稳定再松爪**。

## 4. BR · 感知系统（全自动的眼睛）

| 传感器 | 安装 | 用途 |
|--------|------|------|
| RealSense D435i | 前视（俯仰可调） | 方块检测、颜色朝向、建塔位、塔体、中央柱对中 |
| 超声/TOF ×4–6 | 底盘四周朝下 | 平台边缘防跌落 |
| 限位开关 | 举升上下限、夹爪 | 硬件安全与归零 |
| 编码器/IMU | 底盘 | 里程计、爬坡姿态 |

**识别算法（全部经典 CV，不上重型 DL，保实时+可解释）：**

| 任务 | 方法 | 输出 |
|------|------|------|
| 方块检测 | 深度聚类 + 几何拟合（350/200 立方体尺寸先验） | 位置 + 姿态 |
| 天空块朝向 | HSV 阈值分顶面红/蓝 | 颜色 + 是否需翻转 |
| 建塔位 | HSV 找绿(RGB≈40-100-50) + 500×500 轮廓 | 目标位姿 |
| 已堆塔层数 | 深度高度直方图分层 | 下一层目标高度 |
| 中央柱/凹槽 | 棕色(RGB≈100-62-0)分割 + 圆柱拟合 + 凹槽对中 | 放置点 |

## 5. BR · 决策（行为树状态机）

```
Root (Sequence, 循环至超时)
├── ① 取块: 导航到交接区 → 视觉找块 → 抓取(≤2)
├── ② 建塔: 导航到建塔位 → 视觉对准 → 逐层堆叠(底层→中层→天空)
│       └─ 每层: 举升到目标高 → 视觉精调 → 缓放 → 缩回
├── ③ 判圣所: 完整塔≥2 且 ≥1 共享区?
│       └─ 否→回到②  是→④
├── ④ 取秘宝: 等 TR 放到交接区 → 抓秘宝
├── ⑤ 安放: 爬 L2 阶梯 → 导航中央柱 → 锥罩对中 → 放球 → 确认稳定
└── ⑥ 收尾(剩余时间): 翻对方塔顶天空块 / 补 L2 方块
```
**每个叶子节点带失败恢复：** 抓取失败→重抓(≤3 次)；对准失败→重新定位；块掉落→上报并跳过；导航受阻→重规划；连续失败→自动请求重试(Retry)复位。

## 6. TR 运输机器人 · 设计（纯手动）

| 子系统 | 设计 | 说明 |
|--------|------|------|
| 底盘 | 4 麦轮全向（地面平整，无越障需求） | 灵活平移对准，手动驾驶手感好 |
| 采集 | 前叉抱夹 + 举升 | 一机构兼容 350/200 块 |
| 存储 | 立式 3 工位缓存架 | 1 趟 3 块供 1 座塔 |
| 卸货 | 举升至交接区高度 → 倾倒/推送到放置台 | 放下即走，避开与 BR 空中对接 |
| 取秘宝 | 前叉可下潜至秘宝柱凹槽取球 | 放秘宝交接给 BR |
| 主控 | 树莓派 5 / 工控小板 | 只跑 teleop，负载轻 |
| 遥控 | 蓝牙/USB 手柄 → 笔记本 → **Wi-Fi** → 车 | 符合规则 11.8；链路做看门狗，失联自动停车 |
| 安全 | 红色急停按钮 + 远程急停 | 硬件断电 |

**TR 的唯一 KPI：单次"采集→运输→卸货"循环 ≤ 20 s**（靠操作手训练 + 机构快循环达成）。

## 7. 关键计算校核

### 7.1 爬坡驱动力矩（地面→L1，10°）
- 设 BR 整备质量 m = 40 kg，坡度 θ = 10°，滚动摩擦 μ ≈ 0.05。
- 沿坡阻力 F = mg(sinθ + μcosθ) ≈ 40×9.8×(0.174 + 0.049) ≈ **87 N**。
- 4 轮驱动、轮半径 r = 0.125 m → 单轮力矩 ≈ 87×0.125/4 ≈ **2.7 N·m**。
- 取 2 倍裕量 → **选单轮额定 ≥ 6 N·m 的减速电机**，爬坡绰绰有余。

### 7.2 上台阶（L1→L2，150 mm）
- 台阶高 150 mm < 轮半径 125 mm？**不满足**，故需**前越障导板 + 摆臂**把等效越障高度抬过 150 mm。
- 校核：越障瞬时近似抬升前轮，需前导板提供 ≥ mg/2 ≈ 196 N 的支撑反力 → 导板连杆按 300 N 设计。
- 结论：**靠导板/摆臂几何而非轮径硬翻**，可稳定上 150 mm。

### 7.3 举升速度与节拍
- 行程 800 mm，要求全行程 ≤ 6 s → 平均速度 ≥ 135 mm/s。
- 单层堆叠 ≤ 8 s 分解：举升 3 s + 视觉伺服 2 s + 缓放 2 s + 缩回 1 s。✔ 可达。

### 7.4 电源
- 主电池 24 V LiFePO4（或 6S LiPo），容量按 BR 峰值 300 W × 余量 → 选 24 V / 10 Ah。
- 分压：24 V 直供电机 → DC-DC 12 V（传感器）→ 5 V（主控/逻辑）。

## 8. 电控系统

```
┌────────────── BR 主控: Jetson Orin Nano / 工控机 ──────────────┐
│  ROS2: 感知 + AMCL/Nav2 + 行为树 + ros2_control               │
└───────┬──────────────────────────────┬───────────────────────┘
        │ USB/Ethernet                 │ UART/CAN
   RealSense D435i              ┌───────▼────────┐
                                │ 下位机 STM32     │
                                │ 电机闭环/舵机/限位 │
                                └───┬───────┬────┘
                              4×底盘电机   举升+夹爪
   急停: 红色按钮 → 硬件切断电机动力 (独立于软件)
```
- **BR 主控**：Jetson Orin Nano 8G（视觉+导航算力足）或 x86 工控机。
- **下位机**：STM32F4/F7，负责 4 路电机 PID、举升/夹爪、限位采集；经 UART/CAN 与主控通信（micro-ROS 或自定义协议）。
- **TR 主控**：树莓派 5，仅 teleop + 下位机转发。
- **急停**：硬件级常闭回路切断电机使能，软件急停为辅。

## 9. ROS 2 软件架构（包 / 节点 / 接口）

### 9.1 包职责与关键节点
| 包 | 节点 | 职责 |
|----|------|------|
| `rc_description` | — | URDF/TF、机器人与场地模型 |
| `rc_perception` | `block_detector` | 方块/颜色/建塔位/中央柱识别 |
| `rc_localization` | `amcl`+`robot_localization` | 预制地图定位、轮+IMU 融合 |
| `rc_navigation` | `nav2` 系列 | 全局/局部规划，坡道 costmap |
| `rc_manipulation` | `lift_server`,`gripper_server` | 举升/夹爪动作服务器 |
| `rc_behavior` | `bt_executor` | 行为树编排与异常恢复 |
| `rc_teleop` | `joy`+`teleop_twist_joy` | TR 手动遥控 |
| `rc_msgs` | — | 自定义消息/动作 |
| `rc_bringup` | launch/params | 整机启动 |
| `rc_sim` | gazebo 世界 | 1:1 场地仿真 |

### 9.2 关键接口定义
```
话题:
  /cmd_vel                    geometry_msgs/Twist
  /odom                       nav_msgs/Odometry
  /camera/color/image_raw     sensor_msgs/Image
  /camera/depth/image_rect_raw sensor_msgs/Image
  /detected_blocks            rc_msgs/BlockArray   (位置/姿态/颜色/类型)
  /build_spot_pose            geometry_msgs/PoseStamped

动作 (Action):
  /PickBlock     goal: block_id      result: success
  /PlaceBlock    goal: target_pose   result: success
  /ClimbToLevel  goal: level(1|2)    result: success
  /PlaceMustika  goal: pillar_pose   result: success

TF 树:
  map → odom → base_link → { camera_link, lift_link, gripper_link }
```

### 9.3 开发/调试链路
- 仿真优先：`rc_sim` 里验证导航/爬楼/堆叠/行为树 → 真机迁移。
- 可视化：RViz2（TF/costmap/检测框）、PlotJuggler（爬坡/举升曲线）、rosbag 录赛复盘。

## 13. 风险登记（Top 5）

| 风险 | 概率 | 缓解 |
|------|:----:|------|
| 上 L2 台阶不稳 | 中 | 导板+摆臂冗余、低速大扭矩、防跌传感 |

| 全自动异常卡死 | 中 | 行为树恢复分支、自动 Retry |
| 180 s 节拍不达标 | 高 | 仿真反复压节拍、机构提速、TR/BR 并行 |
